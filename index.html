Sistema de Cadastro de Clientes

Aplicação desktop em Java com interface gráfica em Swing, organizada no padrão MVC (Model–View–Controller). Permite cadastrar clientes pessoa física ou jurídica e consultá-los em uma tela com tabela.

Funcionalidades

  • Formulário de cadastro com nome, documento, tipo (pessoa física ou jurídica) e endereço
  • Botões para limpar o formulário e guardar o cadastro
  • Tela de consulta com tabela de clientes (ID, nome, documento, tipo e endereço)
  • Botão para carregar os clientes e contador de clientes encontrados
  • Código separado em views e controllers

Análise de Dados e Machine Learning — Classificação de Produtos

Projeto acadêmico desenvolvido em grupo, com dados reais de uma empresa do setor farmacêutico. O objetivo foi explorar informações de estoque, demanda, preços e classificação de produtos e testar modelos de Machine Learning para prever a curva dos produtos.

Etapas desenvolvidas

  • Limpeza e preparação dos dados
  • Tratamento de valores ausentes
  • Transformação de variáveis categóricas em numéricas
  • Separação em conjuntos de treino e teste (70% / 30%)
  • Treinamento e avaliação de modelos de classificação
  • Visualização de uma árvore de decisão

Resultado experimental

Um dos testes com o algoritmo DecisionTreeClassifier alcançou aproximadamente 69,64% de acurácia. Outras configurações testadas ficaram entre cerca de 52% e 68%.

Esse valor é um experimento, não um resultado final definitivo: ele usou um subconjunto menor da base (registros com a situação web preenchida), por isso não é diretamente comparável aos demais testes.
